# Optional features

[Documentation](README.md) · [Self-hosting scenarios](self-hosting/README.md)

Install and verify the base recording/transcript flow first. Then follow the
separate setup guide for each feature:

- [Live captions and speech providers](self-hosting/transcription.md).
- [AI summaries](self-hosting/ai-summaries.md): private runtime package, account pool, secrets, activation and checks.
- [Voice answers](self-hosting/voice-answers.md): runtime dependencies, voice assets and Craig playback override.
- [Recording player](self-hosting/recording-playback.md): signing key, HTTPS routing and access checks.
- [Meeting memory](self-hosting/meeting-memory.md): indexing, local replies and release qualification restrictions.

The [preview](preview.md) includes optional output. These features are not all
available from a public clone plus a speech key; each guide states its external
prerequisites and current limitations.
