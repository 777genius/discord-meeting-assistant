# ADR-0063: Reserved live-branch integration decision

## Status

Reserved for the live-branch integration decision. Current retrieval authority
uses ADR-0064; this integration number must not be reused.

## Context

The live branch allocated ADR-0063 independently. Keeping this reservation
prevents two accepted decisions from sharing an identifier while that branch is
integrated.

## Decision

No current-retrieval rule is defined here. The live-branch decision text will
replace this reservation through its own reviewed integration. ADR-0064 owns
composite current/historical retrieval, provenance, snapshots, and generation
fences.
